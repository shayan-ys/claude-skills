# shayan-ys/claude-skills

A Claude Code plugin marketplace of personal skills — Obsidian/PARA vault tooling, Google Docs helpers, research methodology.

## Install the marketplace

    /plugin marketplace add shayan-ys/claude-skills

Then install any plugin:

    /plugin install <plugin-name>@shayan-ys
